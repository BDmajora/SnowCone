# SnowCone

SnowCone is the YetiOS boot/loading screen.

The original live renderer in `main.c` uses Linux DRM/KMS directly. For the
current FreeBSD-based YetiOS alpha, YetiOS generates a static loader-stage
SnowCone bitmap from the same visual theme:

```text
boot/yetios-snowcone.bmp FreeBSD loader-stage static splash generated by YetiOS
```

YetiOS does not install the old text fallback as SnowCone. The next real
SnowCone porting step is replacing the loader-only bitmap with a native FreeBSD
graphics backend for the live renderer.
